Wavelet Analysis Pipeline

Continuous Wavelet Transform and Singularity Spectrum for 1-D, 2-D, 3-D+Time, and multi-band signals

Python 3.9+ NumPy · SciPy · Matplotlib No PyWavelets needed FFT-accelerated CWT WTMM Multifractal

Overview

This pipeline provides a self-contained, dependency-light toolkit for wavelet analysis at any dimensionality. It is designed for researchers and engineers who need to go beyond standard discrete wavelet transforms and require the continuous wavelet transform (CWT) for time-frequency localisation, ridge analysis, and multifractal characterisation.

1-D

Time / 1-D Signals

Full CWT scalogram, global spectrum, ridge detection, Hurst exponent, WTMM singularity spectrum and pointwise Hölder field.

2-D

Images (spatial CWT)

Row-wise, column-wise, or isotropic separable 2-D CWT. Multi-scale power maps for texture and edge analysis.

3-D + Time

Volumetric Time Series

Per-voxel temporal CWT on 4-D arrays (T, D, H, W). Scale-resolved dynamics in volumetric data (fMRI, seismic, simulation).

2-D + N bands

Multi-band Spatial Data

Independent 2-D CWT per spectral band. Cross-band power comparison. Ideal for hyperspectral and multispectral imagery.

Quick Start

import numpy as np
from pipeline import WaveletPipeline

# ── 1. Create pipeline ─────────────────────────────────────────
pipe = WaveletPipeline(
    wavelet="morlet",    # 'morlet' | 'mexican_hat' | 'paul' | 'dog'
    n_scales=64,
    output_dir="./output"
)

# ── 2. Analyze a 1-D signal ────────────────────────────────────
dt = 1 / 512
t  = np.arange(0, 4.0, dt)
x  = np.sin(2*np.pi*10*t) + np.sin(2*np.pi*(50+30*t)*t)

result = pipe.analyze_1d(x, dt=dt)

# Access results
cwt   = result["cwt"]         # CWTResult1D
spec  = result["spectrum"]    # SingularitySpectrum
print(f"Hurst exponent H ≈ {spec.hurst:.4f}")
print(f"Spectrum width  Δα = {spec.width:.4f}")

# ── 3. Analyze a 2-D image ─────────────────────────────────────
rng   = np.random.default_rng(42)
image = np.sin(np.linspace(0, 8*np.pi, 128))[:,None] * \
        np.cos(np.linspace(0, 8*np.pi, 128)) + rng.normal(0, .3, (128,128))

pipe.analyze_2d(image, mode="isotropic")

# ── 4. Multi-band ─────────────────────────────────────────────
bands = {
    "red":   rng.normal(size=(64,64)),
    "green": rng.normal(size=(64,64)),
    "nir":   rng.normal(size=(64,64)),
}
pipe.analyze_multiband(bands)

# ── 5. Run full built-in demo ──────────────────────────────────
pipe.run_demo()

Theory — Continuous Wavelet Transform

The Continuous Wavelet Transform (CWT) of a signal f(t) is defined as:

W(s, τ) = ⟨f, ψs,τ⟩ = (1/√s) ∫ f(t) ψ*((t−τ)/s) dt

where s > 0 is the scale parameter (inversely related to frequency), τ is the translation (time localisation), and ψ is the mother wavelet. The factor 1/√s preserves energy across scales.

Mother Wavelets

NameFormula (time domain)TypeBest for
Morlet π⁻¹⁄⁴ eiω₀t e−t²/2 Complex Oscillatory signals, frequency tracking, ridges
Mexican Hat c (1−t²) e−t²/2 Real Singularity detection, edges, inflection points
Paul (order m) 2mm! / √(π(2m)!) · (1−it)−(m+1) Complex Sharp temporal localisation, fast oscillations
DOG (order m) (−1)m+1/√m! · dm/dtm [G(t)] Real Derivative features, trend removal
ℹ️

The Morlet wavelet with ω₀ = 6 is the default. It provides an excellent balance between time and frequency resolution and satisfies the admissibility condition approximately. For the Mexican hat, the pseudo-frequency is ψ̂(ω) ∝ ω² e−ω²/2, peaking at ω = √2.

Scales and Pseudo-frequencies

The pipeline maps each scale s to an approximate pseudo-frequency:

fpseudo(s) = fc / (s · Δt)

where fc is the centre frequency of the mother wavelet (e.g. ω₀/2π for Morlet). Scales are spaced logarithmically by default (geometric spacing), which gives uniform resolution in frequency on a log scale — appropriate for wide-band analysis.

FFT-based Computation

The pipeline uses the convolution theorem for O(N log N) efficiency:

W(s, ·) = F⁻¹{ F{f} · √(2πs) · Ψ̂*(sω) }

where Ψ̂ is the Fourier transform of the mother wavelet. This is exact (up to edge effects) and avoids the O(N²) cost of direct convolution.

Theory — Singularity Spectrum

The singularity spectrum D(α) is the cornerstone of multifractal analysis. It describes how many points of a signal have a given local regularity (Hölder exponent α).

WTMM Method

The Wavelet Transform Modulus Maxima (WTMM) method, due to Mallat & Hwang (1992) and Muzy, Bacry & Arneodo (1991), avoids the direct partition of space and instead uses the hierarchy of wavelet modulus maxima.

1. CWT W(s,t)
→
2. Modulus maxima
→
3. Partition Z(q,s)
→
4. Scaling τ(q)
→
5. Legendre → D(α)

Step 3 — Partition function

Z(q, s) = Σmaxima l(s) |W(s, tl)|q ~ sτ(q)+1

Step 4 — Scaling exponents

τ(q) is estimated via log-log linear regression of Z(q,s) vs s:

log₂ Z(q, s) = (τ(q)+1) log₂ s + const

Step 5 — Legendre transform

α(q) = dτ/dq      D(α) = q·α(q) − τ(q)

Hölder Exponents

The local Hölder (Lipschitz) exponent α(t₀) measures the pointwise regularity of f at t₀:

|f(t) − Pn(t−t₀)| ≤ C |t−t₀|α(t₀)

where Pn is a polynomial of degree ≤ α. The pipeline estimates α(t) via the dominant scale of the wavelet power cone:

α(t) ≈ log₂|W(s*(t), t)| / log₂ s*(t)

Hurst exponent

For a monofractal (self-similar) signal, the spectrum collapses to a point. The Hurst exponent H ≈ α(q=2) measures self-similarity: H = 0.5 for uncorrelated noise, H > 0.5 for long-range correlated (persistent) signals, H < 0.5 for anti-persistent signals.

⚠️

The WTMM method requires a sufficient number of scales (n_scales ≥ 32) and that the signal is much longer than the largest scale. For short signals (< 512 samples), reduce max_scale or use fewer q-moments.

API — analyze_1d

result = pipe.analyze_1d(
    signal,              # 1-D array (N,)

    q_max = 5.0,        # maximum q moment

    save_figures = True,
    tag = "1d"          # prefix for output files
)

The Mexican hat wavelet is optimal for edge and blob detection in 2-D because it is the Laplacian of Gaussian (LoG) scaled across scales — equivalent to a multi-scale blob detector.

Guide — Adding Custom Wavelets

New wavelets can be added to the registry in wavelets.py with minimal effort. You need to provide at minimum a time-domain function; the frequency-domain version is optional but greatly speeds up computation.

# wavelets.py  — add to the bottom

def shannon(t: np.ndarray) -> np.ndarray:
    """Shannon (sinc) wavelet — ideal bandpass."""
    sinc1 = np.sinc(2*t) * 2
    sinc2 = np.sinc(t)
    return sinc1 - sinc2

def shannon_freq(omega: np.ndarray) -> np.ndarray:
    """Shannon wavelet in frequency domain (exact)."""
    return np.where((np.abs(omega) >= np.pi) & (np.abs(omega) < 2*np.pi), 1.0, 0.0)

# Register it
WAVELET_REGISTRY["shannon"] = {
    "time":    shannon,
    "freq":    shannon_freq,
    "complex": False
}

Then use it directly:

pipe = WaveletPipeline(wavelet="shannon", n_scales=48)
pipe.analyze_1d(signal)

FAQ

Why is the Morlet wavelet the default?

Morlet provides the best joint time-frequency resolution (it saturates the Heisenberg uncertainty bound). It is analytic (complex-valued), so amplitude and phase are directly available. The Mexican hat is real-valued and better for singularity detection but has no phase information.

How many scales do I need?

For qualitative scalograms: 32–64 scales is usually sufficient. For accurate WTMM singularity spectra: at least 48 scales, with the scale range spanning at least two decades (max_scale / min_scale ≥ 100). More scales = finer scale resolution but slower computation.

My singularity spectrum has negative D(α) values — is that wrong?

Not necessarily. For short signals, the Legendre transform may produce slightly negative values in the tails due to finite-size effects. The pipeline filters out D(α) < −0.5 automatically. Values slightly below zero at the spectrum edges are normal and can be interpreted as α values that are present but measure zero (empty set in the mathematical limit).

What is the Cone of Influence (COI)?

At the edges of a finite-length signal, the wavelet at large scales "sees" beyond the signal boundary (edge effects). The COI marks the region where boundary padding effects become significant. Results inside the COI should be interpreted with caution.

Can I use complex-valued input signals?

Yes — the FFT-based CWT naturally handles complex input. Pass the signal as a complex numpy array. The resulting coefficients will be complex. The power |W|² is always real.

What is the difference between scale and frequency?

Scale is the dilation parameter of the wavelet (large scale = stretched wavelet = low frequency; small scale = compressed = high frequency). The pseudo-frequency is an approximation: it is exact only for the Morlet wavelet and approximate for others. Always report in scales for strict mathematical correctness; pseudo-frequencies are a convenience.
