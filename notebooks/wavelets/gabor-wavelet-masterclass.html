L² Spaces, Inner Products & Fourier Theory

Everything rests on the geometry of function spaces. Before we can localize frequencies, we must understand what it means for functions to be orthogonal, to form bases, and to be square-integrable.

The Space L²(ℝ)

The Hilbert space of square-integrable functions over ℝ is defined as:

def 1.1 \[ L^2(\mathbb{R}) = \left\{ f : \mathbb{R} \to \mathbb{C} \;\Big|\; \int_{-\infty}^{\infty} |f(t)|^2 \, dt < \infty \right\} \]

Equipped with the inner product:

def 1.2 \[ \langle f, g \rangle = \int_{-\infty}^{\infty} f(t)\, \overline{g(t)} \, dt \]

and induced norm \(\|f\| = \sqrt{\langle f, f \rangle}\), \(L^2(\mathbb{R})\) is a complete inner product space (Hilbert space). Completeness means every Cauchy sequence converges — essential for discrete approximations to converge to continuous signals.

Definition 1.1 — Orthonormal Basis

A countable set \(\{\phi_n\}_{n \in \mathbb{Z}}\) is an orthonormal basis (ONB) for \(L^2(\mathbb{R})\) if:

\(\langle \phi_m, \phi_n \rangle = \delta_{mn}\) (orthonormality) and every \(f \in L^2(\mathbb{R})\) can be written \(f = \sum_n \langle f, \phi_n \rangle \phi_n\) with convergence in the \(L^2\) norm.

The Fourier Transform

The Fourier transform maps a time-domain signal to its frequency representation:

def 1.3 \[ \hat{f}(\xi) = \mathcal{F}\{f\}(\xi) = \int_{-\infty}^{\infty} f(t)\, e^{-2\pi i \xi t} \, dt \]

The inverse Fourier transform recovers \(f\) from \(\hat{f}\):

def 1.4 \[ f(t) = \mathcal{F}^{-1}\{\hat{f}\}(t) = \int_{-\infty}^{\infty} \hat{f}(\xi)\, e^{2\pi i \xi t} \, d\xi \]
Theorem 1.1 — Plancherel (Parseval)

For \(f, g \in L^1(\mathbb{R}) \cap L^2(\mathbb{R})\):

\[ \langle f, g \rangle = \langle \hat{f}, \hat{g} \rangle \quad\Longleftrightarrow\quad \|f\|^2 = \|\hat{f}\|^2 \]

Energy is conserved under the Fourier transform. The transform extends to an isometric isomorphism on all of \(L^2(\mathbb{R})\).

Short-Time Fourier Transform & the Uncertainty Principle

The global Fourier transform tells us which frequencies are present but not when. The STFT remedies this by windowing — at a fundamental cost encoded by Heisenberg's uncertainty principle.

The Short-Time Fourier Transform

Given a window function \(g \in L^2(\mathbb{R})\) (typically a smooth, compactly supported or rapidly decaying function), the STFT of \(f\) at time \(\tau\) and frequency \(\xi\) is:

def 2.1 \[ \mathcal{V}_g f(\tau, \xi) = \int_{-\infty}^{\infty} f(t)\, \overline{g(t - \tau)}\, e^{-2\pi i \xi t} \, dt \]

This is equivalently the inner product \(\langle f,\, M_\xi T_\tau g \rangle\) where:

def 2.2 \[ T_\tau g(t) = g(t - \tau) \quad \text{(translation operator)} \] \[ M_\xi g(t) = e^{2\pi i \xi t} g(t) \quad \text{(modulation operator)} \]
Theorem 2.1 — STFT Reconstruction (Inversion)

If \(\|g\|_{L^2} = 1\), then for any \(\gamma\) with \(\langle g, \gamma \rangle \neq 0\):

\[ f(t) = \frac{1}{\langle \gamma, g \rangle} \iint_{\mathbb{R}^2} \mathcal{V}_g f(\tau, \xi)\, M_\xi T_\tau \gamma(t) \, d\tau \, d\xi \]

When \(\gamma = g\) (synthesis window = analysis window), this is the standard STFT inversion formula.

Theorem 2.2 — STFT Energy Conservation

\[ \|\mathcal{V}_g f\|_{L^2(\mathbb{R}^2)}^2 = \|g\|^2 \cdot \|f\|^2 \]

If \(\|g\| = 1\): \(\displaystyle\iint |\mathcal{V}_g f(\tau,\xi)|^2 \,d\tau\, d\xi = \|f\|^2\). The spectrogram \(|\mathcal{V}_g f|^2\) is a valid energy distribution in the time-frequency plane.

Heisenberg–Weyl Uncertainty Principle

Define the time spread and frequency spread of \(f\) around centers \(t^*\) and \(\xi^*\):

def 2.3 \[ \Delta_t^2 = \frac{1}{\|f\|^2}\int (t - t^*)^2 |f(t)|^2\, dt \qquad \Delta_\xi^2 = \frac{1}{\|\hat{f}\|^2}\int (\xi - \xi^*)^2 |\hat{f}(\xi)|^2 \, d\xi \]
Theorem 2.3 — Uncertainty Principle (Heisenberg–Weyl)

\[ \Delta_t \cdot \Delta_\xi \geq \frac{1}{4\pi} \]

Equality holds if and only if \(f\) is a Gaussian: \(f(t) = c\, e^{-\alpha(t-t^*)^2}\) for \(\alpha > 0\). The Gaussian is the unique minimizer — this is why Gabor used it.

Critical Implication: No function can be simultaneously perfectly localized in both time and frequency. A sharp time window (\(\Delta_t \to 0\)) implies a broad frequency band (\(\Delta_\xi \to \infty\)) and vice versa. The STFT uses a fixed window — the same \(\Delta_t\), \(\Delta_\xi\) at all frequencies. Wavelets overcome this limitation by using a scaled (variable) window.

§3

Gabor Functions, Atoms & Frames

Dennis Gabor (1946) proposed representing signals using elementary functions that are optimally concentrated in the time-frequency plane — modulated Gaussians, now called Gabor atoms.

Gabor Atoms

A Gabor atom centered at time \(\tau\) and frequency \(\xi\) is the function:

def 3.1 \[ g_{\tau,\xi}(t) = M_\xi T_\tau g(t) = e^{2\pi i \xi t}\, g(t - \tau) \]

The canonical Gabor atom uses the Gaussian window \(g(t) = 2^{1/4} e^{-\pi t^2}\) (normalized so \(\|g\| = 1\)). Its Fourier transform is also Gaussian:

def 3.2 \[ \hat{g}(\xi) = 2^{1/4} e^{-\pi \xi^2} \qquad\Longrightarrow\qquad \widehat{g_{\tau,\xi}}(\nu) = e^{-2\pi i \tau(\nu - \xi)}\,\hat{g}(\nu - \xi) \]

The Gabor transform of \(f\) is simply the STFT with a Gaussian window:

def 3.3 \[ \mathcal{G}f(\tau, \xi) = \langle f, g_{\tau,\xi} \rangle = \int_{-\infty}^{\infty} f(t)\, \overline{g(t-\tau)}\, e^{-2\pi i \xi t}\, dt \]

Gabor Lattices & Frames

In practice, we sample the time-frequency plane on a lattice \(\Lambda = a\mathbb{Z} \times b\mathbb{Z}\) with \(a, b > 0\). The resulting Gabor system is:

def 3.4 \[ \mathcal{G}(g, a, b) = \{ g_{ma, nb} \}_{m,n \in \mathbb{Z}} = \{ e^{2\pi i n b t}\, g(t - ma) \}_{m,n \in \mathbb{Z}} \]
Definition 3.1 — Gabor Frame

The system \(\mathcal{G}(g,a,b)\) is a frame for \(L^2(\mathbb{R})\) if there exist constants \(0 < A \leq B < \infty\) (frame bounds) such that:

\[ A\|f\|^2 \leq \sum_{m,n \in \mathbb{Z}} |\langle f, g_{ma,nb} \rangle|^2 \leq B\|f\|^2 \quad \forall f \in L^2(\mathbb{R}) \]

When \(A = B\), the frame is tight. When \(A = B = 1\) and the system is an ONB, it is a Parseval frame.

Theorem 3.1 — Nyquist Condition (Balian–Low)

If \(\mathcal{G}(g,a,b)\) is an ONB for \(L^2(\mathbb{R})\), then either \(\int t^2|g(t)|^2 dt = \infty\) or \(\int \xi^2|\hat{g}(\xi)|^2 d\xi = \infty\).

Consequence: No ONB Gabor system can have a well-localized (smooth, rapidly decaying) generator. Frames with \(ab < 1\) (overcomplete) avoid this obstruction and allow smooth, well-localized \(g\).

Frame Operator & Dual Frame

The Gabor frame operator \(S : L^2(\mathbb{R}) \to L^2(\mathbb{R})\) is:

def 3.5 \[ Sf = \sum_{m,n} \langle f, g_{ma,nb} \rangle\, g_{ma,nb} \]

The frame bounds \(A\), \(B\) satisfy \(A \cdot \text{Id} \leq S \leq B \cdot \text{Id}\) in the operator sense. The canonical dual frame generator is \(\tilde{g} = S^{-1}g\), giving the reconstruction formula:

thm 3.2 \[ f = \sum_{m,n} \langle f, g_{ma,nb} \rangle\, \tilde{g}_{ma,nb} = \sum_{m,n} \langle f, \tilde{g}_{ma,nb} \rangle\, g_{ma,nb} \]

2D Gabor Filters (Images)

For 2D signals (images) \(f(x,y)\), the Gabor filter at orientation \(\theta\), frequency \(\xi_0\), and scale \(\sigma\) is:

def 3.6 \[ g_{\sigma,\theta,\xi_0}(x,y) = \frac{1}{2\pi\sigma^2} \exp\!\left(-\frac{x'^2 + \gamma^2 y'^2}{2\sigma^2}\right) \cos(2\pi \xi_0 x' + \psi) \]

where \(x' = x\cos\theta + y\sin\theta\), \(y' = -x\sin\theta + y\cos\theta\), \(\gamma\) is the spatial aspect ratio, and \(\psi\) is the phase offset. A filter bank samples \(\theta \in \{0, \pi/K, \ldots, (K-1)\pi/K\}\) and multiple scales \(\sigma\).

§4

Continuous Wavelet Transform & Admissibility

Unlike the STFT's fixed-width window, the CWT adapts its time resolution to the scale being analyzed — wide windows for low frequencies, narrow windows for high frequencies — achieving constant relative bandwidth (constant Q-factor).

The Continuous Wavelet Transform

Given a mother wavelet \(\psi \in L^2(\mathbb{R})\), the CWT of \(f\) at scale \(a > 0\) and translation \(b \in \mathbb{R}\) is:

def 4.1 \[ W_\psi f(a, b) = \langle f, \psi_{a,b} \rangle = \frac{1}{\sqrt{a}} \int_{-\infty}^{\infty} f(t)\, \overline{\psi\!\left(\frac{t-b}{a}\right)} dt \]

where the normalized wavelet atoms are \(\psi_{a,b}(t) = a^{-1/2}\,\psi\!\left(\frac{t-b}{a}\right)\). The factor \(a^{-1/2}\) ensures \(\|\psi_{a,b}\| = \|\psi\|\) for all scales.

Admissibility Condition

Definition 4.1 — Admissibility

A function \(\psi \in L^2(\mathbb{R})\) is an admissible wavelet (mother wavelet) if the following condition holds:

\[ C_\psi = \int_0^\infty \frac{|\hat{\psi}(\xi)|^2}{\xi} d\xi < \infty \]

A necessary condition is \(\hat{\psi}(0) = 0\), i.e., \(\int_{-\infty}^\infty \psi(t)\,dt = 0\) — the wavelet must have zero mean (oscillatory).

Theorem 4.1 — CWT Reconstruction (Calderón)

If \(\psi\) is admissible with constant \(C_\psi < \infty\), then:

\[ f(t) = \frac{1}{C_\psi} \int_0^\infty \int_{-\infty}^{\infty} W_\psi f(a,b)\, \psi_{a,b}(t)\, \frac{da\, db}{a^2} \]

Theorem 4.2 — CWT Energy Conservation

\[ \|f\|^2 = \frac{1}{C_\psi} \int_0^\infty \int_{-\infty}^{\infty} |W_\psi f(a,b)|^2\, \frac{da\, db}{a^2} \]

The scalogram \(|W_\psi f(a,b)|^2\) distributes energy over the scale-translation (time-scale) plane.

Discrete Wavelet Transform & Filterbank Theory

The DWT discretizes scale on a dyadic grid, connecting wavelet theory to perfect-reconstruction filterbanks and enabling O(N) computation — the Fast Wavelet Transform.

Dyadic Wavelet Lattice

Restricting scale to \(a = 2^j\) and translation to \(b = k \cdot 2^j\), the DWT coefficients are:

def 5.1 \[ d_j[k] = \langle f, \psi_{j,k} \rangle = 2^{-j/2} \int f(t)\, \overline{\psi(2^{-j}t - k)} \, dt \]

Detail coefficients \(d_j[k]\) capture information at scale \(2^j\). Approximation coefficients at the coarsest level are:

def 5.2 \[ a_J[k] = \langle f, \phi_{J,k} \rangle = 2^{-J/2} \int f(t)\, \overline{\phi(2^{-J}t - k)}\, dt \]

where \(\phi\) is the scaling function associated to \(\psi\) via multiresolution analysis (§6).

Two-Scale Relations & Filterbanks

The fundamental two-scale (dilation) equations link the scaling function and wavelet to low- and high-pass filters:

def 5.3 \[ \phi(t) = \sqrt{2}\sum_{k \in \mathbb{Z}} h[k]\, \phi(2t - k) \qquad \psi(t) = \sqrt{2}\sum_{k \in \mathbb{Z}} g[k]\, \phi(2t - k) \]

where \(h[k]\) is the lowpass filter and \(g[k] = (-1)^k\overline{h[1-k]}\) is the highpass filter (quadrature mirror filter). The DWT at each level performs:

def 5.4 \[ a_{j+1}[k] = \sum_n h[n - 2k]\, a_j[n] \qquad d_{j+1}[k] = \sum_n g[n - 2k]\, a_j[n] \]

This is convolution with the filter followed by downsampling by 2 — achievable in \(O(N)\) per level, giving total complexity \(O(N)\) for the full decomposition.

Theorem 5.1 — Perfect Reconstruction Conditions

A two-channel filterbank \((H, G)\) achieves perfect reconstruction if and only if:

\[ \hat{H}(\xi)\overline{\hat{H}(\xi + 1/2)} + \hat{G}(\xi)\overline{\hat{G}(\xi+1/2)} = 0 \quad\text{(alias cancellation)}\]

\[ |\hat{H}(\xi)|^2 + |\hat{G}(\xi)|^2 = 2 \quad\text{(no-distortion / power complementary)}\]

Daubechies Filter Coefficients

The \(D_4\) (Daubechies 4-tap) lowpass filter — the simplest smooth compactly supported wavelet:

ex 5.1 \[ h = \left[\frac{1+\sqrt{3}}{4\sqrt{2}},\ \frac{3+\sqrt{3}}{4\sqrt{2}},\ \frac{3-\sqrt{3}}{4\sqrt{2}},\ \frac{1-\sqrt{3}}{4\sqrt{2}}\right] \approx [0.483,\ 0.836,\ 0.224,\ -0.129] \]

Wavelet Packet Transform

The standard DWT only splits the approximation subspace at each level. The wavelet packet transform (WPT) splits both approximation and detail subbands, producing a full binary tree of subspaces. The WPT generates a library of \(2^J\) possible orthonormal bases for a signal of length \(2^J\), enabling best-basis selection (Coifman-Wickerhauser):

def 5.5 \[ W_{j+1,2p}[k] = \sum_n h[n-2k]\,W_{j,p}[n], \quad W_{j+1,2p+1}[k] = \sum_n g[n-2k]\,W_{j,p}[n] \]
§6

Multiresolution Analysis

Multiresolution analysis (Mallat, 1989) provides the rigorous functional-analytic framework that unifies scaling functions, wavelets, and filterbanks into a coherent theory of nested approximation spaces.

Definition 6.1 — Multiresolution Analysis (MRA)

A sequence of closed subspaces \(\{V_j\}_{j \in \mathbb{Z}}\) of \(L^2(\mathbb{R})\) is an MRA if:

(i) Nesting: \(\cdots \subset V_{-1} \subset V_0 \subset V_1 \subset \cdots\)

(ii) Density & separation: \(\overline{\bigcup_j V_j} = L^2(\mathbb{R})\) and \(\bigcap_j V_j = \{0\}\)

(iii) Scaling: \(f(t) \in V_j \Leftrightarrow f(2t) \in V_{j+1}\)

(iv) Shift-invariance: \(f(t) \in V_0 \Rightarrow f(t-k) \in V_0\) for all \(k \in \mathbb{Z}\)

(v) Basis: \(\exists\, \phi \in V_0\) such that \(\{\phi(t-k)\}_{k \in \mathbb{Z}}\) is an ONB for \(V_0\).

Orthogonal Complement Decomposition

Define the wavelet subspace \(W_j\) as the orthogonal complement of \(V_j\) in \(V_{j+1}\):

def 6.1 \[ V_{j+1} = V_j \oplus W_j, \qquad V_j \perp W_j \]

Iterating:

thm 6.1 \[ L^2(\mathbb{R}) = V_{J_0} \oplus \bigoplus_{j \geq J_0} W_j = \bigoplus_{j \in \mathbb{Z}} W_j \]

The wavelet \(\psi\) generates an ONB for each \(W_j\): \(\{\psi_{j,k}\}_{k \in \mathbb{Z}}\) is an ONB for \(W_j\), and \(\{\phi_{J_0, k}\}_{k \in \mathbb{Z}} \cup \{\psi_{j,k} : j \geq J_0, k \in \mathbb{Z}\}\) is an ONB for \(L^2(\mathbb{R})\).

Projection & Approximation Error

The projection of \(f\) onto \(V_j\) gives the best \(V_j\)-approximation:

def 6.2 \[ P_{V_j} f = \sum_{k \in \mathbb{Z}} a_j[k]\, \phi_{j,k}, \qquad a_j[k] = \langle f, \phi_{j,k}\rangle \]

The approximation error decreases as \(j \to \infty\): for \(f \in W^s_2(\mathbb{R})\) (Sobolev space), \(\|f - P_{V_j}f\| = O(2^{-js})\) as \(j \to \infty\), provided \(\phi\) has enough vanishing moments.

Vanishing Moments

Definition 6.2 — Vanishing Moments

A wavelet \(\psi\) has \(N\) vanishing moments if \(\int t^k \psi(t)\, dt = 0\) for \(k = 0, 1, \ldots, N-1\).

Consequence: The DWT of a smooth signal has small detail coefficients — polynomial signals of degree \(< N\) are exactly represented in \(V_j\) and produce zero detail coefficients. More vanishing moments → better compression of smooth signals → Daubechies \(D_{2N}\) has exactly \(N\) vanishing moments.

Algorithmic CWT via FFT: The convolution \(W_\psi f(\cdot, b) = f * \overline{\tilde\psi_{a}}(b)\) (where \(\tilde\psi_a(t) = a^{-1/2}\psi(-t/a)\)) is computed as pointwise multiplication in the Fourier domain:

alg 7.1 \[ W_\psi f(a, \cdot) = \mathcal{F}^{-1}\!\Big\{ \hat{f}(\xi) \cdot \sqrt{a}\,\overline{\hat\psi(a\xi)} \Big\} \]

Complexity: \(O(N_a \cdot N \log N)\) where \(N_a\) is the number of scales. Typical: \(N_a \in [32, 512]\) covering 4–8 octaves.

Scale selection: Logarithmically spaced scales covering the desired frequency range:

alg 7.2 \[ a_j = a_{\min} \cdot 2^{j/n_v}, \quad j = 0, 1, \ldots, N_a - 1, \quad n_v = \text{voices per octave} \]

Cone of Influence (COI): At scale \(a\), edge effects propagate up to \(\sqrt{2}\,a\) samples from each boundary. Coefficients inside the COI are unreliable and should be masked.

Boundary handling options:

Zero-padding
Extend with zeros. Simple, causes Gibbs-like artifacts at boundaries.
Symmetric (reflect)
Mirror the signal at boundaries. Preserves smoothness. Default in scipy/PyWavelets.
Periodic
Wrap-around. Correct for periodic signals, introduces discontinuity otherwise.

Python Implementation

Python · NumPy / PyWavelets / SciPy 1d_wavelet_pipeline.py 
import numpy as np
import pywt
from scipy import signal
import matplotlib.pyplot as plt

# ── 1. Generate or load 1D signal ─────────────────────────────────────
Fs  = 1000                          # sampling rate (Hz)
N   = 4096                          # number of samples (2^12)
t   = np.arange(N) / Fs
x   = (np.sin(2*np.pi*10*t) * (t < 2)   # 10 Hz, first 2 s
     + np.sin(2*np.pi*40*t) * (t >= 2))  # 40 Hz, after 2 s
x  += 0.3 * np.random.randn(N)     # add noise

# ── 2. CWT via FFT convolution ────────────────────────────────────────
def cwt_fft(x, scales, wavelet='cmor1.5-1.0', Fs=1):
    """Efficient CWT using FFT multiplication."""
    N = len(x)
    Xf = np.fft.fft(x, n=N)
    freqs = np.fft.fftfreq(N, d=1/Fs)
    coefs = np.zeros((len(scales), N), dtype=complex)
    for i, a in enumerate(scales):
        # Morlet in frequency domain: Ψ*(aξ)
        xi = freqs * a / Fs
        psi_f = np.where(xi > 0,
                  np.exp(-0.5*(xi - 2*np.pi*1.5)**2), 0)
        coefs[i] = np.fft.ifft(Xf * np.conj(psi_f) * np.sqrt(a))
    return coefs

scales  = np.logspace(np.log10(1), np.log10(100), 64)
W       = cwt_fft(x, scales, Fs=Fs)
scalogram = np.abs(W)**2

# ── 3. DWT decomposition + soft thresholding ──────────────────────────

coeffs  = pywt.wavedec(x, wavelet, level=level, mode='symmetric')

# Estimate noise σ from finest detail (universal threshold)

lam     = sigma * np.sqrt(2 * np.log(N))

                             for c in coeffs[1:]]
x_denoised = pywt.waverec(thresh, wavelet, mode='symmetric')[:N]

hop     = 64                         # hop size (75% overlap)

    x, fs=Fs, window='gaussian',
    nperseg=win_len, noverlap=win_len-hop)

Pipeline: 2D Signals (Images)

For 2D signals \(f(x,y)\), the wavelet and Gabor transforms must capture spatial frequency content at multiple orientations. The separable 2D DWT is the workhorse of image compression (JPEG 2000), while 2D Gabor banks drive texture analysis and edge detection.

2D DWT — Separable Extension

The separable 2D DWT applies 1D filterbanks along rows then columns independently. One level produces four subbands from image \(f(x,y)\):

def 8.1 \[ \begin{aligned} LL[k,l] &= (f *_{row} h *_{col} h)[\downarrow 2, \downarrow 2] &&\text{(approx)}\\ LH[k,l] &= (f *_{row} h *_{col} g)[\downarrow 2, \downarrow 2] &&\text{(horiz. edges)}\\ HL[k,l] &= (f *_{row} g *_{col} h)[\downarrow 2, \downarrow 2] &&\text{(vert. edges)}\\ HH[k,l] &= (f *_{row} g *_{col} g)[\downarrow 2, \downarrow 2] &&\text{(diagonal)} \end{aligned} \]

Only \(LL\) is recursively decomposed. After \(J\) levels, the total number of coefficients equals the number of pixels (critical sampling, no redundancy in the orthogonal case).

2D DWT — 3-Level Subband Decomposition
Level 1:  [LL₁ | LH₁ | HL₁ | HH₁]  →  each ¼ of original size
Level 2:  [LL₂ | LH₂ | HL₂ | HH₂]  →  each ¹⁄₁₆ of original
Level 3:  [LL₃ | LH₃ | HL₃ | HH₃]  →  each ¹⁄₆₄ of original
Final output: 1×LL₃ + 3×LH/HL/HH per level = 10 subbands total

Non-Separable 2D Wavelets

Separable 2D DWT has limited directional selectivity (only 3 orientations). Non-separable alternatives:

Curvelets (Candès)
Near-optimal sparse representation of edges. O(n^{-2}) decay for C² curves. Parabolic scaling: width ~ length².
Contourlets (Do-Vetterli)
Discrete-domain directional filterbank. Separates multiscale (Laplacian pyramid) from directional decomposition.
Shearlets (Kutyniok)
Mathematically complete directional system. Unified framework with optimal sparsity theory for anisotropic features.
Dual-tree CWT
Two parallel DWT trees giving 6 orientations in 2D, approximate shift-invariance. Selesnick et al.

2D Gabor Filter Bank

A complete 2D Gabor filter bank samples \(K\) orientations and \(S\) scales:

def 8.2 \[ G_{s,k}(x,y) = \frac{1}{2\pi\sigma_s^2}\exp\!\left(-\frac{x_k'^2 + y_k'^2/\gamma^2}{2\sigma_s^2}\right)\exp\!\left(2\pi i \frac{x_k'}{\lambda_s}\right) \]

where \(\theta_k = k\pi/K\), \(x_k' = x\cos\theta_k + y\sin\theta_k\), \(\lambda_s = \lambda_{\min}\cdot r^s\) (geometric scale progression, \(r \approx \sqrt{2}\)). Typical: \(K \in \{4,6,8\}\), \(S \in \{3,4,5\}\) → 12 to 40 filter responses per pixel.

import numpy as np
import pywt
from scipy.ndimage import convolve

# ── 2D DWT decomposition ──────────────────────────────────────────────
def dwt2_multilevel(img, wavelet='db4', level=3):
    """J-level 2D DWT. Returns dict of all subband coefficients."""
    coeffs = pywt.wavedec2(img, wavelet, level=level, mode='symmetric')
    # coeffs[0] = LL_J (approximation)
    # coeffs[j] = (LH_{J-j+1}, HL_{J-j+1}, HH_{J-j+1}) for j=1..J
    return coeffs

def dwt2_denoise(img, wavelet='db4', level=3, mode='soft'):
    coeffs = dwt2_multilevel(img, wavelet, level)
    # Estimate noise from finest diagonal detail
    sigma = np.median(np.abs(coeffs[-1][2])) / 0.6745
    lam   = sigma * np.sqrt(2 * np.log(img.size))
    # Threshold all detail subbands
    thresh = [coeffs[0]]
    for lh, hl, hh in coeffs[1:]:
        thresh.append(tuple(pywt.threshold(c, lam, mode=mode)
                            for c in (lh, hl, hh)))
    return pywt.waverec2(thresh, wavelet, mode='symmetric')

# ── 2D Gabor filter bank ──────────────────────────────────────────────
def gabor_kernel(sigma, theta, lamda, gamma=0.5, psi=0, ksize=31):
    """Generate a 2D Gabor kernel."""
    c, s = np.cos(theta), np.sin(theta)
    x = np.arange(-ksize//2, ksize//2+1)
    xg, yg = np.meshgrid(x, x)
    xr = xg*c + yg*s
    yr = -xg*s + yg*c
    envelope = np.exp(-(xr**2 + gamma**2 * yr**2) / (2*sigma**2))
    carrier  = np.cos(2*np.pi*xr/lamda + psi)
    return envelope * carrier

def gabor_filterbank(img, n_orients=6, n_scales=4,
                      lam_min=4, lam_max=32):
    """Apply Gabor filter bank and return energy responses."""
    thetas  = [k*np.pi/n_orients for k in range(n_orients)]
    lambdas = np.geomspace(lam_min, lam_max, n_scales)
    responses = []
    for lam in lambdas:
        sigma = lam * 0.56                    # bandwidth ≈ 1 octave
        for theta in thetas:
            k_re = gabor_kernel(sigma, theta, lam, psi=0)    # cosine
            k_im = gabor_kernel(sigma, theta, lam, psi=np.pi/2) # sine
            r_re = convolve(img.astype(float), k_re)
            r_im = convolve(img.astype(float), k_im)
            responses.append(np.sqrt(r_re**2 + r_im**2))  # energy
    return np.stack(responses, axis=-1)   # (H, W, n_orients*n_scales)

# ── Usage ─────────────────────────────────────────────────────────────
from skimage import data, color
img   = color.rgb2gray(data.astronaut()).astype(np.float32)

Pipeline: 3D Signals (2D + Time — Video, fMRI)

Spatiotemporal signals require joint analysis of spatial texture and temporal dynamics. The 3D DWT and spatiotemporal Gabor banks are the two primary tools, each with distinct computational profiles and interpretive strengths.

3D Separable DWT

For a volume \(f(x, y, t)\) of size \(M \times N \times T\), the separable 3D DWT applies 1D filterbanks along each axis. One decomposition level produces \(2^3 = 8\) subbands:

def 9.1 \[ \{LLL, LLH, LHL, LHH, HLL, HLH, HHL, HHH\}_{j} \]

where L = lowpass, H = highpass applied along dimensions (x, y, t) respectively. Only \(LLL_j\) is recursively decomposed. After \(J\) levels: \(7J + 1\) subbands total.

Spatiotemporal Gabor Filters

The 3D Gabor filter for motion analysis decomposes into a spatial 2D component and temporal 1D component (separable form for efficiency):

def 9.2 \[ G(\mathbf{x}, t) = G_{2D}(x, y; \sigma_{xy}, \theta) \cdot G_{1D}(t; \sigma_t, \omega_t) \]

The non-separable fully 3D Gabor atom oriented along spatiotemporal direction \((\theta, \phi)\) (spatial angle, velocity angle) is:

def 9.3 \[ G(\mathbf{r}, t;\, \sigma, \xi_0, v_0, \theta) = \frac{1}{(2\pi)^{3/2}\sigma^3} e^{-\frac{x'^2+y'^2+\tau^2}{2\sigma^2}} e^{2\pi i(\xi_0 x' + \omega_0 \tau)} \]

where \(\tau = t - v_0^{-1}(x\cos\theta + y\sin\theta)\) is the co-moving time coordinate and \(\omega_0 = \xi_0 / v_0\) is the temporal frequency at velocity \(v_0\).

Motion Detection via Spatiotemporal Filtering

Motion energy is extracted as:

alg 9.1 \[ E(\mathbf{x}, t; v) = |f * G^{\cos}|^2 + |f * G^{\sin}|^2 \]

where \(G^{\cos}\) and \(G^{\sin}\) differ only in phase (0 and \(\pi/2\)). The energy \(E\) is maximized when the local spatiotemporal pattern matches velocity \(v\). This is the Adelson-Bergen motion energy model (1985), the neural substrate of motion perception in V1.

import numpy as np
import pywt
from scipy.ndimage import convolve

# ── 3D DWT via repeated 2D+1D ─────────────────────────────────────────
def dwt3_level(volume, wavelet='db4'):
    """One level of 3D separable DWT on volume (T, H, W)."""
    M, N, T = volume.shape
    # Step 1: apply 2D DWT spatially to each frame
    spatial = np.zeros((M, N, T))
    coeffs_spatial = {}
    for t in range(T):
        c = pywt.dwt2(volume[:,:,t], wavelet, mode='symmetric')
        # c = (LL, (LH, HL, HH))
        spatial[:M//2, :N//2, t] = c[0]         # LL
        spatial[M//2:, :N//2, t] = c[1][0]      # LH
        spatial[:M//2, N//2:, t] = c[1][1]      # HL
        spatial[M//2:, N//2:, t] = c[1][2]      # HH
    # Step 2: apply 1D DWT temporally to each spatial coefficient
    out = np.zeros((M, N, T//2 * 2))
    for i in range(M):
        for j in range(N):
            lo, hi = pywt.dwt(spatial[i,j,:], wavelet, mode='symmetric')
            T2 = min(len(lo), T//2)
            out[i, j, :T2]    = lo[:T2]   # low-freq temporal
            out[i, j, T//2:T//2+T2] = hi[:T2] # high-freq temporal
    return out  # 8 subbands encoded in spatial blocks × temporal halves

# ── Spatiotemporal Gabor filter (separable) ───────────────────────────
def st_gabor_filter(volume, sigma_xy, sigma_t, theta, xi_xy, omega_t):
    """
    Separable spatiotemporal Gabor filter.
    volume: (H, W, T) float array
    Returns complex energy response (H, W, T).
    """
    H, W, T = volume.shape
    x = np.arange(W) - W/2
    y = np.arange(H) - H/2
    t = np.arange(T) - T/2
    xx, yy = np.meshgrid(x, y)
    xr = xx*np.cos(theta) + yy*np.sin(theta)
    yr = -xx*np.sin(theta) + yy*np.cos(theta)

    # 2D spatial Gabor kernel (complex)
    env_xy = np.exp(-(xr**2 + yr**2) / (2*sigma_xy**2))
    car_xy = np.exp(2j*np.pi*xi_xy*xr)
    k_xy   = env_xy * car_xy    # (H, W)

    # 1D temporal Gabor kernel (complex)
    k_t = np.exp(-t**2 / (2*sigma_t**2)) * np.exp(2j*np.pi*omega_t*t)

    # Separable convolution: first spatial, then temporal
    resp = np.zeros((H, W, T), dtype=complex)
    for ti in range(T):
        resp[:,:,ti] = convolve(volume[:,:,ti].astype(complex),
                                k_xy.astype(complex), mode='wrap')
    for i in range(H):
        for j in range(W):
            resp[i,j,:] = np.convolve(resp[i,j,:], k_t, mode='same')
    return np.abs(resp)**2    # motion energy

# ── Usage: video motion energy ─────────────────────────────────────────
# video: (H, W, T) float32 grayscale
video = np.random.randn(64, 64, 32).astype(np.float32)

    sigma_xy=5, sigma_t=3, theta=0,
    xi_xy=0.1, omega_t=0.2)
print(f"Motion energy tensor: {energy.shape}")  # (64, 64, 32)

Pipeline: 2D + N Bands (Hyperspectral Signals)

Hyperspectral imagery \(f(x, y, \lambda)\) — with \(N\) spectral channels per pixel, \(N \in [10, 400]\) — requires joint spatial-spectral analysis. Wavelet and Gabor transforms extend naturally across the spectral dimension, enabling compressed sensing, unmixing, and anomaly detection.

Signal Model

setup \[ f : \Omega \times \Lambda \to \mathbb{R}, \quad \Omega \subset \mathbb{R}^2 \text{ (spatial)}, \quad \Lambda = \{\lambda_1, \ldots, \lambda_N\} \text{ (spectral bands)} \] \[ \text{Data tensor: } \mathbf{F} \in \mathbb{R}^{M \times N_{px} \times N_{bands}} \]

Band-wise 2D DWT

The simplest approach: apply 2D DWT independently to each spectral band \(\lambda_k\):

def 10.1 \[ \{LL^{(k)}, LH^{(k)}, HL^{(k)}, HH^{(k)}\} = \text{DWT}_2(f(\cdot, \cdot, \lambda_k)), \quad k = 1, \ldots, N \]

This ignores inter-band correlation. For hyperspectral data, adjacent bands are highly correlated (\(\rho > 0.95\)) — a major inefficiency.

3D Wavelet Transform (Spatial × Spectral)

Treating the spectral dimension as a third axis, the 3D DWT exploits inter-band correlations directly:

def 10.2 \[ \mathbf{W} = \text{DWT}_3(\mathbf{F}) \in \mathbb{R}^{M/2^J \times N_{px}/2^J \times N/2^{J_\lambda}} \oplus \text{detail subbands} \]

Design consideration: The spectral axis is not a spatial axis — wavelet regularity requirements may differ. Often a different wavelet (e.g., linear predictive, \(D_2\) Haar) is used spectrally, while \(D_4\) or \(D_8\) is used spatially.

Spectral-Spatial Gabor Features

A spectral Gabor filter at center wavelength \(\bar\lambda\) and spectral bandwidth \(\sigma_\lambda\):

def 10.3 \[ G_{\bar\lambda, \sigma_\lambda}(\lambda) = e^{-(\lambda - \bar\lambda)^2/(2\sigma_\lambda^2)} \cos\!\left(\frac{2\pi(\lambda - \bar\lambda)}{\Lambda_0}\right) \]

Combined with a 2D spatial Gabor filter \(G_{2D}(x,y;\sigma_{xy},\theta,\xi_0)\), the full spectral-spatial Gabor response at pixel \((x,y)\) is:

def 10.4 \[ R_{\bar\lambda,\theta}(x,y) = \sum_k G_{\bar\lambda,\sigma_\lambda}(\lambda_k) \cdot (f(\cdot,\cdot,\lambda_k) *_{xy} G_{2D}^{\theta})(x,y) \]

Compressed Sensing for Hyperspectral

If \(\mathbf{F}\) is \(K\)-sparse in the 3D wavelet domain (\(K \ll MN_{px}N\)), we can reconstruct from \(m \approx CK\log(MN_{px}N/K)\) random linear measurements:

thm 10.1 (RIP) \[ \hat{\mathbf{F}} = \arg\min_{\mathbf{X}} \|\mathbf{W}\mathbf{X}\|_1 \quad \text{subject to} \quad \|\mathbf{A}\mathbf{X} - \mathbf{y}\|_2 \leq \epsilon \]

where \(\mathbf{A} \in \mathbb{R}^{m \times MN_{px}N}\) is the measurement matrix (random Gaussian or structured), and \(\mathbf{W}\) is the 3D wavelet operator. Recovery succeeds when \(\mathbf{A}\mathbf{W}^{-1}\) satisfies the Restricted Isometry Property (RIP) at order \(2K\).

import numpy as np
import pywt
from sklearn.decomposition import PCA

# ── Hyperspectral data: (rows, cols, bands) ───────────────────────────
# Example: AVIRIS / Sentinel-2 / PRISMA cube
H, W, N_bands = 256, 256, 200
cube = np.random.randn(H, W, N_bands).astype(np.float32)  # synthetic

# ── Strategy 1: Band-wise 2D DWT ──────────────────────────────────────
def bandwise_dwt2(cube, wavelet='db4', level=3):
    """Independent 2D DWT per spectral band."""
    H, W, N = cube.shape
    coeffs_all = []
    for b in range(N):
        c = pywt.wavedec2(cube[:,:,b], wavelet, level=level)
        coeffs_all.append(c)
    return coeffs_all

# ── Strategy 2: PCA + Band-wise DWT (decorrelate first) ───────────────
def pca_wavelet(cube, n_components=20, wavelet='db4', level=3):
    """KL-transform then 2D DWT on principal components."""
    H, W, N = cube.shape
    X = cube.reshape(-1, N)          # (H*W, N_bands)
    pca = PCA(n_components=n_components)
    scores = pca.fit_transform(X)     # (H*W, n_components)
    # Reshape each PC to image and apply 2D DWT
    pc_imgs = scores.reshape(H, W, n_components)
    dwt_coeffs = []
    for pc in range(n_components):
        c = pywt.wavedec2(pc_imgs[:,:,pc], wavelet, level=level)
        dwt_coeffs.append(c)
    return pca, dwt_coeffs

# ── Strategy 3: 3D DWT (spatial + spectral joint) ─────────────────────
def dwt3_hyperspectral(cube, spatial_wav='db4', spectral_wav='db2',
                        sp_level=3, spec_level=4):
    """
    3D DWT: separable spatial (2D) + spectral (1D) decomposition.
    Different wavelets for spatial vs spectral (common in practice).
    """
    H, W, N = cube.shape
    # First: spectral DWT along band axis per pixel
    spec_coeffs_cube = np.zeros_like(cube)
    for i in range(H):
        for j in range(W):
            spec_c = pywt.wavedec(cube[i,j,:], spectral_wav,
                                     level=spec_level, mode='symmetric')
            recon = pywt.waverec(spec_c, spectral_wav, mode='symmetric')[:N]
            spec_coeffs_cube[i,j,:] = recon  # store spectral approx
    # Then: 2D spatial DWT on each spectral coefficient plane
    spatial_coeffs = []
    for b in range(N):
        c = pywt.wavedec2(spec_coeffs_cube[:,:,b], spatial_wav,
                             level=sp_level, mode='symmetric')
        spatial_coeffs.append(c)
    return spatial_coeffs

# ── Spectral-Spatial Gabor Feature Extraction ─────────────────────────
def spectral_spatial_gabor(cube, spec_centers, spec_sigma,
                             orientations=4, spatial_scales=3):
    """
    Extract spectral-spatial Gabor features.
    Returns (H, W, len(spec_centers)*orientations*spatial_scales).
    """
    from scipy.ndimage import convolve
    H, W, N = cube.shape
    band_idx = np.arange(N)
    features = []

    for lam_c in spec_centers:
        # Spectral Gabor weighting
        spec_weights = np.exp(-(band_idx - lam_c)**2 / (2*spec_sigma**2))
        weighted_spatial = np.einsum('hwb,b->hw', cube, spec_weights)

        # 2D spatial Gabor bank on spectrally-weighted image
        for s in range(spatial_scales):
            sigma_xy = 4 * (2**s)
            lam_xy   = sigma_xy * 2
            ksize    = 4*int(sigma_xy)+1
            for k in range(orientations):
                theta = k * np.pi / orientations
                x_ = np.arange(-ksize//2, ksize//2+1)
                xg, yg = np.meshgrid(x_, x_)
                xr = xg*np.cos(theta) + yg*np.sin(theta)
                yr = -xg*np.sin(theta) + yg*np.cos(theta)
                env = np.exp(-(xr**2 + yr**2) / (2*sigma_xy**2))
                k_re = env * np.cos(2*np.pi*xr/lam_xy)
                k_im = env * np.sin(2*np.pi*xr/lam_xy)
                r_re = convolve(weighted_spatial, k_re)
                r_im = convolve(weighted_spatial, k_im)
                features.append(np.sqrt(r_re**2 + r_im**2))

    return np.stack(features, axis=-1)   # (H, W, n_features)

# ── Anomaly detection: Wavelet-Reed-Xiaoli (Wavelet-RX) ───────────────
def wavelet_rx_anomaly(cube, wavelet='db4', level=2, n_pca=10):
    """
    Wavelet-domain RX anomaly detector for hyperspectral imagery.
    RX: Reed-Xiaoli detector — Mahalanobis distance from mean spectrum.
    """
    H, W, N = cube.shape
    pca, dwt_c = pca_wavelet(cube, n_pca, wavelet, level)
    # Reconstruct wavelet approximation in PCA space
    approx = np.zeros((H, W, n_pca))
    for pc in range(n_pca):
        # Zero detail coefficients (keep only approx)
        c = dwt_c[pc]
        zeros = [c[0]] + [(np.zeros_like(lh), np.zeros_like(hl), np.zeros_like(hh))
                          for lh,hl,hh in c[1:]]
        approx[:,:,pc] = pywt.waverec2(zeros, wavelet)[:H,:W]
    X_approx = approx.reshape(-1, n_pca)
    mu = X_approx.mean(axis=0)
    C_inv = np.linalg.pinv(np.cov(X_approx.T))
    diff = X_approx - mu
    rx = np.einsum('ij,jk,ik->i', diff, C_inv, diff)  # Mahalanobis²
    return rx.reshape(H, W)                              # anomaly score map

Application
Wavelet/Gabor Method
Remote sensing compression
CCSDS 122.0-B: the space image compression standard. Uses 3D DWT (spatial 2D + spectral 1D) with Daubechies wavelets. Lossless and lossy modes.
Exploits high inter-band correlation. Typical compression: 4:1 lossless, 20:1 lossy with negligible spectral distortion.
Material classification
Gabor spectral-spatial features capture both spectral signature (material identity) and spatial texture (surface roughness, structure). SVM classification.
Outperforms pure spectral classifiers on spatially heterogeneous scenes. Orientation + scale diversity critical for mineral mapping.
Anomaly detection
Wavelet-RX, Dual Window-RX. Wavelet domain decorrelates background → sharper Mahalanobis distance for anomalies.
Wavelet preprocessing removes background spatial autocorrelation that inflates false alarm rate in pixel-domain RX. 2–5× improvement in ROC AUC.
Spectral unmixing
DWT denoising before NMF/sparse unmixing. Spectral Gabor features as spatial regularization in unmixing optimization.
Joint spatial-spectral constraints encoded as wavelet-domain sparsity priors → better endmember separation in mixed pixels.

Complexity & Redundancy Summary

Transform
Computational Complexity
1D CWT (FFT)
O(N_a · N log N)
N_a scales, N samples. Redundancy: N_a × oversampled.
1D DWT (Mallat)
O(N · |h|)
|h| = filter length. Critically sampled. Zero redundancy.
2D DWT (separable)
O(MN · |h|)
MN pixels. 3 detail subbands per level. Critically sampled.
2D Gabor bank
O(K · S · MN log(MN))
K orientations, S scales. Redundancy: K×S. Via FFT convolution.
3D DWT (video)
O(MNT · |h|)
Separable: T frames × O(MN). Critically sampled in all 3 axes.
3D DWT (hyperspectral)
O(MN · N_bands · |h|)
Spectral DWT: O(N_bands·|h|) per pixel. Spatial: O(MN·|h|) per band.
Spectral-Spatial Gabor
O(K_spec · K_orient · S · MN log(MN))
High redundancy. Suitable for feature extraction, not compression.
